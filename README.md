# Netflix Data Analysis

## Project Overview
This project explores the Netflix movies and TV shows dataset to identify patterns in content distribution, genres, countries, and release years.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## Analysis Performed
- Compared the number of movies and TV shows
- Explored popular genres and categories
- Analyzed content distribution by country
- Examined release-year trends

## Skills Demonstrated
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data aggregation using Pandas
- Data visualization
- Communicating insights from data

## Files
- `Netflix_Analysis.ipynb` — analysis notebook
- `netflix.csv` — dataset used in the project

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries: `pandas` and `matplotlib`.
3. Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab.
4. Run the cells in order.
